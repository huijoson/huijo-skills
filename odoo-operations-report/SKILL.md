# Odoo 維運報告

依已提供的紀錄製作可交付報告。預設使用繁體中文並產出同名 `.html` 與 `.md`；使用者指定單一格式時，只產出該格式。本技能負責報告整理，不因補齊報告而重跑維運操作。

## 1. 收斂資料與修訂

以對話最新確認的內容為準，沿用已決定的欄位、刪除項目與語氣。輸入可以是 MCP 回傳摘要、操作追蹤結果、既有報告或使用者貼上的文字；直接使用已有資料，只有關鍵衝突會影響結論時才提問。

逐環境整理一份共用資料：環境名稱、主機識別（若提供）、實際執行範圍、時間與來源、流程狀態、退出碼、啟動腳本結果、警告及操作編號。兩種格式由這份資料衍生。缺少的值寫「未提供」；有衝突的值保留來源並標示待釐清。

完成條件：每個環境均有對應資料，能區分已知、缺漏、推算與衝突，並已納入使用者的歷次修訂。

## 2. 整理時間與證據

- 沿用來源明示的時區；本工作流程預設以臺灣時間（UTC+8）呈現。來源時區不明時註明，僅在來源時區已知時換算。
- 開始時間採執行紀錄，操作編號代表的控制端請求時間不能替代執行開始時間。預設省略啟動請求時間欄。
- 已記錄的完成時間優先；缺漏且開始時間與流程總耗時齊全時，以「開始時間＋總耗時」推算並加註來源。跨日時顯示日期；耗時範圍不同或資料矛盾時保留差異，避免硬湊時間。
- 主機時鐘有偏差時，保留原值與偏差說明，推算的完成時間承接相同限制；不自行將約略偏差當成校正值。
- 分別陳述流程狀態、退出碼與啟動腳本結果。僅在資料支持時寫成功；混合成功、失敗、進行中或未知的環境應分別呈現。
- 啟動腳本成功返回僅支持腳本執行成功。若尚無健康檢查證據，在摘要簡述驗證範圍；實際健康狀態已有驗證時按結果描述。
- `not installable, skipped` 表示該模組未納入更新。警告未使流程失敗，不等於沒有功能影響；依來源記錄，未知影響標示尚未驗證。

完成條件：時間計算可核對，結果措辭未超出證據，所有環境的失敗、跳過或未知狀態均有呈現。

## 3. 套用輸出範本

僅讀取需要的格式，複製範本到輸出檔後填入資料：

- HTML：使用 [assets/report-template.html](assets/report-template.html)，保留自包含樣式、橫向捲動表格與列印版面。
- Markdown：使用 [assets/report-template.md](assets/report-template.md)，保持相同事實、列順序與註記。

預設章節為執行摘要、執行範圍、執行時間、執行結果、更新期間發現及操作追蹤編號。非更新任務將「更新期間發現」改為「操作期間發現」，並依實際步驟填寫範圍。沒有資料的非必要章節可整段移除。

「待確認項目」、「更新後日誌與服務確認」與啟動請求時間依使用者要求才加入；既有報告明確保留的內容則沿用。使用者刪除內容後，後續轉換格式也保持刪除結果。

範本以 `{{名稱}}` 表示替換點。`*_ROWS`、`*_ITEMS`、`*_NOTES`、`FINDING_GROUPS` 是由共用資料產生的格式片段，其餘為文字。HTML 片段只包含範本需要的標籤，來源文字先做 HTML 跳脫；Markdown 表格儲存格須處理 `|`、換行及原始 HTML。以純文字呈現來源中的程式碼或日誌，不執行或嵌入來源提供的腳本。

輸出到使用者指定位置；未指定時使用工作環境的產物目錄或系統暫存目錄，檔名採 `odoo-operations-report-YYYY-MM-DD`。更新既有報告時沿用該檔案；新報告遇同名檔則加時間或環境後綴。僅在使用者要求原始碼時以程式碼區塊代替檔案。

報告可保留使用者提供且需要呈現的主機識別；發佈技能的範本與測試資料使用占位符或合成資料，不攜入真實 inventory、操作編號或 credential。輸出前遮蔽來源中的密碼、token 與 private key。

完成條件：要求的檔案已寫出，範本替換點全數處理，刪除項目沒有因套版而回復。

## 4. 核對與交付

核對所有環境的開始時間、完成時間、耗時、結果及操作編號；推算需涵蓋進位與跨日。檢查 HTML 標籤、表格結構與本機可開啟性；有瀏覽器預覽工具時查看窄螢幕及列印版面。Markdown 檢查表格欄數與特殊字元。雙格式核對資料與註記一致，不以瀏覽器檢查取代內容核對。

回覆可點擊的產物路徑。若仍有會影響解讀的缺漏，簡述限制。以檔案已生成且核對完成為交付條件。
